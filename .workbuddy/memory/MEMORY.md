# 科技周报项目记忆

## 写作规范

- **优先级规则**：新模型发布 > 模型价格变动 > 产业/算力 > 安全事件
- 头条三条优先选模型发布和价格类新闻，安全事件归入"其他重要新闻"
- 采用第8-10期风格（客观新闻简报型），不使用 `---` 分割线
- 标题用中文顿号分隔3个核心事件
- 结尾 `## 其他重要新闻` + `> [!tip] 此栏目将每周更新`

## Front Matter 模板

```yaml
---
title: "标题（顿号分隔）"
description: "科技周报：YYYY年M月D日-M月D日，AI模型领域重大事件盘点"
date: YYYY-MM-DDT00:00:00+08:00
lastmod: YYYY-MM-DDT00:00:00+08:00
categories:
    - 科技周报
tags:
    - AI
draft: false
---
```
