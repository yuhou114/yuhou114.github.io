本题目为[1493. 删掉一个元素以后全为 1 的最长子数组](https://leetcode.cn/problems/longest-subarray-of-1s-after-deleting-one-element/description/)

给你一个二进制数组 nums ，你需要从中删掉一个元素。  

请你在删掉元素的结果数组中，返回最长的且只包含 1 的非空子数组的长度。  

如果不存在这样的子数组，请返回 0 。  

***

- 提示 1：  

> 输入：nums = [1,1,0,1]  
> 输出：3  
> 解释：删掉位置 2 的数后，[1,1,1] 包含 3 个 1 。  

- 示例 2：  

> 输入：nums = [0,1,1,1,0,1,1,0,1]  
> 输出：5  
> 解释：删掉位置 4 的数字后，[0,1,1,1,1,1,0,1] 的最长全 1 子数组为 [1,1,1,1,1] 。  

- 示例 3：  

> 输入：nums = [1,1,1]  
> 输出：2  
> 解释：你必须要删除一个元素。  
 


>[!tip]
> - 1 <= nums.length <= 10^5  
> - nums[i] 要么是 0 要么是 1 。  

***

## 题解

### 核心思想

此类不定长滑动窗口（越短越合法）思路见[无重复字符的最长子串]({{< relref "post/算法-滑动窗口/无重复字符的最长子串" >}})

ans：答案长度    
right：右指针  
left：左指针  
本题重点在于一定要删除一个元素，因此ans的值就不是right - left + 1 而是 right - left。   

```java
class Solution {
    public int longestSubarray(int[] nums) {
        int ans = 0;
        int left = 0;
        int cnt = 0; //记录0出现的次数
        int n = nums.length;
        for(int right = 0; right < n; right++){
            if(nums[right] == 0){
                cnt++;
            }
            
            while(cnt == 2){
                if(nums[left] == 0){
                    cnt--;
                }
                left++;
            }

            ans = Math.max(ans, right - left);
        }
        return ans;
    }
}
```
