本题目为[3090. 每个字符最多出现两次的最长子字符串](https://leetcode.cn/problems/maximum-length-substring-with-two-occurrences/description/)

给你一个字符串 s ，请找出满足每个字符最多出现两次的最长子字符串，并返回该子字符串的 最大 长度。  

***

- 示例 1：  

> 输入： s = "bcbbbcba"  
> 输出： 4  
> 解释：以下子字符串长度为 4，并且每个字符最多出现两次："bcbbbcba"。  

- 示例 2：  

> 输入： s = "aaaa"  
> 输出： 2  
> 解释：以下子字符串长度为 2，并且每个字符最多出现两次："aaaa"。  
 
>[!tip]  
> - 2 <= s.length <= 100  
> - s 仅由小写英文字母组成。  
 
***

## 题解

### 核心思想

此类不定长滑动窗口（越短越合法）思路见[无重复字符的最长子串]({{< relref "post/算法-滑动窗口/无重复字符的最长子串" >}})  

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        char[] ss = s.toCharArray();
        int ans = 0;
        int n = ss.length;
        int[] cnt = new int[128]; //ascll表位数
        int left = 0;
        for(int right = 0; right < n; right++){
            char c = ss[right];
            cnt[c]++;

            while (cnt[c] > 2) { //有重复元素
                cnt[ss[left]]--; //移除左边窗口字母
                left++; //窗口缩小
            }

            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```
