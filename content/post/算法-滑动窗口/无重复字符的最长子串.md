本题目为[3.无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/description/)

给定一个字符串 s ，请你找出其中不含有重复字符的 **最长 子串** 的长度。

***

- 示例 1:  

> 输入: s = "abcabcbb"  
> 输出: 3   
> 解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。  
 
- 示例 2:  

> 输入: s = "bbbbb"  
> 输出: 1  
> 解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。  

- 示例 3:

> 输入: s = "pwwkew"  
> 输出: 3  
> 解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。  
>      请注意，你的答案必须是 子串 的长度，"pwke" 是一个子序列，不是子串。  
 

>[!tip]
> 0 <= s.length <= 5 * 10^4
> s 由英文字母、数字、符号和空格组成

***

## 题解

### 核心思想

首先找子串判断为滑动窗口，由于子串长度不固定，采取双指针的方式来查找。当查找到当前s[i]在map里的value > 1时，移除左边窗口字母且窗口缩小，如下图所示。本题解为了效率使用数组等效于使用HashMap

### 举例
示例，s=abcbb。

1. 从左到右遍历 s。  
2. s[0]=a 进入窗口，此时子串为a，更新答案最大值，无重复继续。  
3. s[1]=b 进入窗口，此时子串为ab，更新答案最大值，无重复继续。  
4. s[2]=c 进入窗口，此时子串为abc，更新答案最大值，无重复继续。  
5. s[3]=b 进入窗口，此时子串为abcb，有重复逐个移除当前窗口最左边元素，直到不重复；此时子串为cb，更新答案最大值，继续。  
6. s[4]=b 进入窗口，此时子串为cbb，有重复逐个移除当前窗口最左边元素，直到不重复；此时子串为b，更新答案最大值。遍历结束。  


```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        char[] ss = s.toCharArray();
        int ans = 0;
        int n = ss.length;
        int[] cnt = new int[128]; //ascll表位数
        int left = 0;
        for(int right = 0; right < n; right++){
            char c = ss[right];
            cnt[c]++;

            while (cnt[c] > 1) { //有重复元素
                cnt[ss[left]]--; //移除左边窗口字母
                left++; //窗口缩小
            }

            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```
