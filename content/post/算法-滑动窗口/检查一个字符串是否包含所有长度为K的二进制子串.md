本题目为[1016.检查一个字符串是否包含所有长度为 K 的二进制子串](https://leetcode.cn/problems/check-if-a-string-contains-all-binary-codes-of-size-k/description/)

给你一个二进制字符串 s 和一个整数 k 。如果所有长度为 k 的二进制字符串都是 s 的子串，请返回 true ，否则请返回 false 。

***

- 示例 1：

> 输入：s = "00110110", k = 2  
> 输出：true  
> 解释：长度为 2 的二进制串包括 "00"，"01"，"10" 和 "11"。它们分别是 s 中下标为 0，1，3，2 开始的长度为 2 的子串。  

- 示例 2：

> 输入：s = "0110", k = 1  
> 输出：true  
> 解释：长度为 1 的二进制串包括 "0" 和 "1"，显然它们都是 s 的子串。  

- 示例 3：

> 输入：s = "0110", k = 2  
> 输出：false  
> 解释：长度为 2 的二进制串 "00" 没有出现在 s 中。  
 

>[!tip]
> 1 <= s.length <= 5 * 10^5  
> s[i] 不是'0' 就是 '1'  
> 1 <= k <= 20  

***

## 题解

### 核心思想

通用思路见[定长子串中元音的最大数目]({{< relref "post/算法-滑动窗口/定长子串中元音的最大数目" >}})

本题思路在于子串转成整数，保存到布尔数组中，用暴力也可以但时间接近上限。

```java
class Solution {
    public boolean hasAllCodes(String s, int k) {
        // 1. 定义掩码：保留最后 k 位二进制数
        final int MASK = (1 << k) - 1;
        // 2. 标记数组：索引对应二进制子串的整数值，值表示是否出现过
        boolean[] has = new boolean[1 << k];
        // 3. 统计已出现的不同子串数量
        int cnt = 0;
        // 4. 存储当前滑动窗口内二进制子串对应的整数
        int x = 0;

        // 遍历字符串，提前退出条件：已找到所有子串
        for (int i = 0; i < s.length() && cnt < (1 << k); i++) {
            char ch = s.charAt(i);
            
            // 核心：滚动计算下一个子串的整数值
            // 步骤1：x 左移1位 → 空出最后一位放新字符
            // 步骤2：与 MASK 相与 → 去掉超出 k 位的高位（滑动窗口左移一位，丢弃最左字符）
            // 步骤3：或上 (ch&1) → 将新字符放到最后一位
            x = (x << 1 & MASK) | (ch & 1);

            // 当 i >= k-1 时，才形成第一个完整的长度为 k 的子串
            if (i >= k - 1 && !has[x]) {
                has[x] = true; // 标记该子串已出现
                cnt++; // 计数+1
            }
        }

        // 最终判断：是否找到所有 2^k 个子串
        return cnt == (1 << k);
    }
}
```
