本题目为[1695. 删除子数组的最大得分](https://leetcode.cn/problems/maximum-erasure-value/description/)

给你一个正整数数组 nums ，请你从中删除一个含有 若干不同元素 的子数组。删除子数组的 得分 就是子数组各元素之 和 。  

返回 只删除一个 子数组可获得的 最大得分 。  

如果数组 b 是数组 a 的一个连续子序列，即如果它等于 a[l],a[l+1],...,a[r] ，那么它就是 a 的一个子数组。  

***

- 示例 1：

> 输入：nums = [4,2,4,5,6]  
> 输出：17  
> 解释：最优子数组是 [2,4,5,6]  

- 示例 2：

> 输入：nums = [5,2,1,2,5,2,1,2,5]  
> 输出：8  
> 解释：最优子数组是 [5,2,1] 或 [1,2,5]  
 

>[!tip]
> 1 <= nums.length <= 10^5  
> 1 <= nums[i] <= 10^4  

***

## 题解

### 核心思想

此类不定长滑动窗口（越短越合法）思路见[无重复字符的最长子串]({{< relref "post/算法-滑动窗口/无重复字符的最长子串" >}})

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int maximumUniqueSubarray(int[] nums) {
        int ans = 0;
        int left = 0;
        Map<Integer, Integer> cnt = new HashMap<>();
        int sum = 0;
        for(int i = 0; i < nums.length; i++){
            int c = nums[i];
            cnt.merge(c, 1, Integer::sum); //入
            sum += c;

            while(cnt.get(c) > 1){ //出
                int out = nums[left];
                sum -= out;
                cnt.merge(out, -1, Integer::sum);
                if(cnt.get(out) == 0){
                    cnt.remove(out);
                }
                left++;
            }

            ans = Math.max(ans, sum); //更新答案
        }
        return ans;
    }
}
```
